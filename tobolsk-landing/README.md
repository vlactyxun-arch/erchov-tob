# Тобольск глазами Ершова

Одностраничный туристический маршрут на русском языке. В архиве исходный код, данные, материалы и проектная документация.

## Запуск

Требуется Node.js 22 и npm. Из папки проекта выполните:

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Для демонстрации формы скопируйте .env.example в .env.local. При LEAD_DEMO=true форма валидирует заявку без отправки.

```sh
npm run lint
npm run build
npm start
```

Для запуска приёма заявок задайте TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID, проверьте права бота в чате и отключите LEAD_DEMO. Для индексации задайте абсолютный NEXT_PUBLIC_SITE_URL. ORGANIZER_NAME включает разметку LocalBusiness. До публикации замените временные фото и заполните сведения об организаторе и обработке данных.

## GitHub Pages

Workflow .github/workflows/pages.yml собирает статическую версию при push в main. В настройках Pages источник публикации должен быть GitHub Actions. В версии на Pages кнопка записи ведёт на действующую страницу маршрута, где размещена форма организаторов. Серверная сборка продолжает использовать собственный API заявки.

## Структура

- app/ — страница, стили и API заявок
- components/ — секции, общие компоненты и элементы интерфейса
- content/ — данные маршрута в JSON
- lib/ — типы, валидация и события аналитики
- public/ — локальные материалы
- docs/ — требования, архитектура, дизайн, задачи и решения
