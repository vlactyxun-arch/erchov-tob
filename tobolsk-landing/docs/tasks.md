- `npm run lint` и `npm run build` завершились успешно.
- Первая версия. Lighthouse 12.8.2, мобильный профиль Edge, локальная production-сборка. Performance 95, Accessibility 100, LCP 2,9 с, CLS 0.
- После обновления оформления проверены загрузка Manrope, вёрстка и основные сценарии в Edge на 320 и 1440 px.
- Edge на ширинах 320 и 1440 px. Проверены отсутствие горизонтальной прокрутки, фото первого экрана, переключение дней, перенос параметров в форму, валидация полей, демо-отправка, FAQ и синхронизация точки карты с карточкой. На странице доступны семь маркеров.
- API проверено на синтетических данных. Пройдены сценарии группы из восьми участников и индивидуальной поездки. Отклонены группа из семи человек, заполненный honeypot, отсутствие согласия и неизвестная локация.
- Telegram, Метрика, домен и публикация требуют данных организатора. Конверсию и глубину прокрутки оценивают после запуска.
