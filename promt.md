# Единый промт для Codex / нейросети-разработчика

> Скопируй целиком в Codex (или другой агентный инструмент) как задачу. Он должен создать папку `tobolsk-landing/` с файлами `docs/` и упаковать в ZIP.

---

## РОЛЬ
Ты — senior full-stack разработчик и UI/UX-дизайнер. Ты работаешь в терминале, умеешь создавать файлы и папки, запускать команды. Твоя задача — на основе брифа заказчика спроектировать и реализовать одностраничный лендинг туристического маршрута «Тобольск глазами Ершова», а также собрать всю проектную документацию в папку `docs/` и упаковать всё в ZIP-архив.

## ЖЁСТКИЕ ТРЕБОВАНИЯ
- Использовать открытые библиотеки стилей (Tailwind CSS, shadcn/ui, Framer Motion, Lenis).
- **НЕ использовать шаблоны ИИ** (никаких «AI-generic» лендингов с тремя карточками и синим градиентом).
- Строго следовать сетке UI/UX (8pt grid, типографическая шкала, единая система отступов).
- Добавить анимации и «вау-эффект» — но аккуратно, без «всё летает».
- Шрифт — в стиле старых вывесок Тобольска (историческая антиква/акцидент; кандидаты: Cormorant Garamond, PT Serif, Ruslan Display — финал после визуальных якорей заказчика).
- Палитра строго светлая, тёплая, историческая. Тёмная палитра ЗАПРЕЩЕНА.
- Никаких туристических клише (пальмы, самолётики, чемоданы).

## БРИФ (сводка)

### 1. Главное действие (Primary CTA)
«Заказать звонок» → форма обратной связи:
- количество человек **от 8** по готовой программе на 2–3 дня;
- ИЛИ индивидуальный тур с конструированием программы из списка локаций.

### 2. Второстепенное действие
Запрос программы для группы.

### 3. Тональность
Атмосферный и эмоциональный:
- «Новое прочтение города»
- «Тобольск глазами Ершова»
- «Город — это люди, проекты и концепции, которые создают единый образ»

### 4. Заголовки
- H1: «Тобольск глазами Ершова»
- Подзаголовок: «Тобольск, который ты не видел»

### 5. Первый экран
Обязательно: фото/картинка (от заказчика) + логотипы партнёров.

### 6. Визуальные референсы
- `nadspb.ru` — структура выбора (для себя / в подарок + фильтрация). Адаптация: выбор по количеству человек.
- `silavetra.com/travel/greece` — атмосфера.
- `visittyumen.ru/excursions-and-tours/` — **основной референс**: стиль, шрифты, структура.

### 7. Чего НЕ должно быть
Перегруженный дизайн, туристические клише, тёмная палитра, агрессивные продажи, тяжёлая анимация.

### 8. Тип сайта
Одностраничный лендинг с якорной навигацией (кнопка → скролл к нужному блоку на этой же странице).

### 9. Обязательные блоки (все отмечены в брифе)
1. Первый экран с названием
2. Короткое описание маршрута
3. Расписание и даты
4. Программа по времени
5. Карта маршрута
6. Объекты маршрута с фото
7. Рестораны / гастрономия
8. Стоимость и что входит
9. Как добраться, справ. инф.
10. Отзывы, истории гостей
11. Для кого маршрут
12. Что взять с собой / особенности
13. Другое

### 10. Расписание
Фиксированные даты + возможность запроса индивидуального подбора и расписания.

### 11. Актуальность
Показывать «ближайшие даты от 8 человек».

### 12. Цены
- Индивидуальный тур с проживанием в отеле — **от 33 000 ₽**
- Групповой с проживанием в хостеле — **от 19 800 ₽ / чел.**
- Групповой с проживанием в отеле — **от 28 000 ₽ / чел.**
- Доп. пожелания и количество дней обсуждаемы (2 или 3 дня) — цена изменяема.

### 13. Варианты
Группа / индивидуально; 2 дня / 3 дня; минимум **8 человек** для группового формата; индивидуальный — заявка.

### 14. Палитра
Светлая, тёплая, историческая, природная (как на референсах).

### 15. Доп. пожелания
Заказчик пришлёт визуальные якоря с формулировками — предусмотреть в дизайне «слоты» под них.

## ЧТО СДЕЛАТЬ (пошагово)

### Шаг 1. Создать структуру
```
tobolsk-landing/
├── docs/
│   ├── PRD.md
│   ├── architecture.md
│   ├── rules.md
│   ├── design.md
│   ├── tasks.md
│   └── memory.md
└── README.md
```

### Шаг 2. Заполнить `docs/` полным содержанием (не заглушками)

**`docs/PRD.md`**
- Цели, метрики (CR ≥ 3%, scroll-depth ≥ 40%, Lighthouse ≥ 90)
- ЦА, User Stories
- Функциональные требования по 14 секциям
- Нефункциональные: адаптив 320–1920, WCAG AA, SEO, аналитика
- MoSCoW, вне скоупа, критерии приёмки

**`docs/architecture.md`**
- Стек: Next.js 14 (App Router) + TS (strict) + Tailwind + shadcn/ui + Framer Motion + Lenis + Leaflet/Yandex Maps + zod
- Дерево проекта (app/, components/ui, components/sections, components/shared, content/, lib/, public/, docs/)
- Типы: Day, Location, ScheduleSlot, Tariff, Review, FAQItem, Lead
- API `POST /api/lead` с zod-валидацией и отправкой в Telegram/CRM
- SEO: metadata, OG, JSON-LD TouristTrip + LocalBusiness
- Аналитика: cta_click, form_submit, scroll_depth, map_point_click
- Хостинг Vercel + env-переменные

**`docs/rules.md`**
- 8pt grid, типографическая шкала (H1 64/56, H2 40, H3 28, body 17, small 14)
- Радиусы 8/16/24, мягкие тени
- A11y: WCAG AA, focus-visible, семантика, alt
- Performance: Lighthouse ≥ 90, next/image, preload шрифтов
- Motion: только Framer Motion, 200–500 мс, easing [0.22,1,0.36,1], respect prefers-reduced-motion
- Запрещено: тёмная палитра, агрессивные модалки, autoplay-видео со звуком
- Код: ESLint + Prettier, strict TS, no any, Conventional Commits
- Контент: русский, tone атмосферный

**`docs/design.md`**
- Концепция: «Новое прочтение Тобольска», город = люди
- Палитра: `--bg #FAF6EF`, `--ink #1F1A14`, `--accent #A24E2C`, `--accent-soft #D9B99B`, `--sage #6B7A5A`, `--gold #C9A227`
- Типографика: акцидентный исторический шрифт + Inter/PT Sans
- Сетка 12 колонок, max-width 1240, gutter 24
- Motion: reveal-on-scroll, лёгкий parallax, hover-карточки, crossfade дней, прокрутка точек карты
- «Вау»: ken-burns hero + рукописный акцент, таймлайн с прогресс-линией, синхронизация карты и карточек
- Слот `#anchors` под визуальные якоря заказчика

**`docs/tasks.md`** — чек-лист из 12 эпиков (инициализация → дизайн-система → Hero → About+Audience → Program → Locations → Map → Schedule+Pricing → Food/Reviews/Info/FAQ → Contact → Motion → SEO/QA/Deploy).

**`docs/memory.md`**
- Договорённости из брифа
- Принятые решения (стек, контент в JSON, карта Leaflet с заменой на Yandex)
- Открытые вопросы (визуальные якоря, финальные фото, список локаций с координатами, отзывы, точные даты, лицензия шрифта)
- Риски
- Changelog

**`README.md`** — быстрый старт и структура.

### Шаг 3. Инициализировать Next.js-проект в `tobolsk-landing/`
```
npx create-next-app@latest . --ts --tailwind --eslint --app --src-dir=false --import-alias="@/*"
npm i framer-motion lenis zod lucide-react leaflet react-leaflet clsx tailwind-merge
npx shadcn@latest init
npx shadcn@latest add button card badge accordion input select tabs dialog
```

### Шаг 4. Дизайн-токены
- `tailwind.config.ts`: палитра из `design.md`, шрифты, spacing scale
- `app/globals.css`: CSS-переменные, подключение шрифтов через next/font, базовые стили
- `lib/utils.ts`: cn() для классов

### Шаг 5. Компоненты
- `components/ui/*` — shadcn-атомы
- `components/shared/Header.tsx` — sticky-навигация с якорями + CTA
- `components/shared/Footer.tsx`
- `components/sections/Hero.tsx`, `About.tsx`, `Audience.tsx`, `Program.tsx`, `Locations.tsx`, `MapSection.tsx`, `Schedule.tsx`, `Pricing.tsx`, `Food.tsx`, `Reviews.tsx`, `Info.tsx`, `FAQ.tsx`, `Contact.tsx`
- `components/shared/Reveal.tsx` — обёртка Framer Motion с respect prefers-reduced-motion
- `components/shared/SmoothScroll.tsx` — Lenis

### Шаг 6. Контент
Создать `content/*.json`:
- `locations.json` — 6–8 локаций (заглушки + TODO для заказчика)
- `days.json` — 3 дня по времени
- `tariffs.json` — 3 тарифа (33 000 / 19 800 / 28 000)
- `schedule.json` — ближайшие даты + seatsLeft
- `reviews.json` — 3–4 заглушки
- `faq.json` — 5–6 вопросов

### Шаг 7. Форма
- `app/api/lead/route.ts`: zod-схема Lead, honeypot, заглушка отправки в Telegram Bot API через env
- `components/sections/Contact.tsx`: react-hook-form + zodResolver, поля: имя, телефон, кол-во человек (от 8), формат (группа/индивидуально), 2/3 дня, комментарий
- Состояния: loading / success / error

### Шаг 8. Анимации
- Framer Motion reveal на всех секциях
- Лёгкий parallax в Hero
- Hover карточек: scale 1.02 + shadow
- Crossfade при переключении дней
- Lenis smooth scroll
- Всё под `prefers-reduced-motion`

### Шаг 9. SEO + аналитика
- `app/layout.tsx`: metadata, OG, шрифты
- JSON-LD TouristTrip + LocalBusiness
- `lib/analytics.ts` — события cta_click, form_submit, scroll_depth

### Шаг 10. Проверка
- `npm run build` без ошибок
- `npm run lint` без ошибок
- Lighthouse: Performance ≥ 90, Accessibility ≥ 95

### Шаг 11. Упаковать
```
cd ..
zip -r tobolsk-landing.zip tobolsk-landing -x "*/node_modules/*" "*.DS_Store" "*/.next/*"
```
Вывести путь к `tobolsk-landing.zip` и дерево файлов (без node_modules).
